Mutual Funds Dashboard

Scrape live mutual fund market data from Yahoo Finance using Python, Requests and BeautifulSoup. Display fund information dynamically with Flask.

About This Project

This project demonstrates static web scraping by collecting live mutual fund information from Yahoo Finance. Python Requests retrieves the webpage, BeautifulSoup parses the HTML and Flask displays the extracted financial data.
