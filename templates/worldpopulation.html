🌍 Static Web Scraping Project

World Population Scraper

Extract live country-wise population statistics from the Worldometers website using Python, Requests and BeautifulSoup. The scraped data is displayed dynamically using Flask.

About This Project

This project demonstrates static web scraping using Python. The application sends an HTTP request to the Worldometers website, parses the HTML content using BeautifulSoup and extracts live population statistics for countries around the world. The extracted data is displayed dynamically in a responsive table using Flask templates.

Challenges Faced

The website contains a large HTML table, requiring careful inspection of rows and columns for accurate extraction.

HTTP Requests

Browser request headers were added to prevent the website from blocking automated requests.

Data Cleaning

The extracted data was cleaned and formatted before being displayed inside the HTML table.
