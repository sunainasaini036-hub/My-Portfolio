📡 API Scraping Project

JSONPlaceholder API Explorer

Fetch and display live JSON data using Python, Requests, REST API integration and Flask. This project demonstrates how API responses are converted into dynamic web pages.

About This Project

JSONPlaceholder is a free fake REST API used for testing and learning API integration. This project retrieves posts using Python Requests, processes the JSON response and dynamically displays the results using Flask templates.
