Wikipedia Information Extractor

Static Web Scraping Project using Python, Requests, BeautifulSoup and Pandas

Official Website

View Project →

This project demonstrates static web scraping by extracting structured information from Wikipedia articles using Python, Requests and BeautifulSoup. The scraper collects article titles, paragraphs, section headings, infobox details and Wikipedia tables, then converts them into structured datasets using Pandas for further analysis.
